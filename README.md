# vishnu.rengaraj.com

Personal site for Vishnu Rengaraj. Vue 3 and Vite, prerendered to static HTML. The title screen keeps the 2023 starfield, sunset gradient, and parallax treeline. Below that, the page uses a dark Material 3 Expressive scheme seeded from the sunset orange.

```bash
npm ci
npm run dev
npm run build
```

The built site is rooted at `https://vishnu.rengaraj.com`. `rengaraj.com` and `www` redirect there. Hosting notes are in [DEPLOY.md](DEPLOY.md). Copy lives in `src/data/content.js`. Published images and video are in `public/media/`. Originals are in `media-src/`.
